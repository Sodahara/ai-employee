# 原価企画・ライフサイクルコスト分析

## このスキルが発動する条件
- 「原価企画」「ライフサイクルコスト」「LCC」「コスト削減」「コスト構造」

## 手順
1. 対象製品・システムのコスト構成要因（設計・調達・製造・運用・保守・廃棄等）を、取得〜廃棄までのライフサイクル全体で分解する
2. 開発・設計段階での削減には、目標原価を先に設定し、そこから設計・調達に落とし込む原価企画（ターゲットコスティング）の考え方を使う
3. 各要因のコストドライバーと削減余地（設計変更・調達方法の見直し等）を、VE（Value Engineering：機能とコストの関係を整理する手法）の視点で特定する
4. 削減施策ごとの効果（コスト削減率・影響範囲）を試算する
5. 以下のフォーマットで整理する

## 出力フォーマット
```
# [対象製品/システム] コスト分析

## ライフサイクルコスト構成
| ライフサイクル段階（取得/運用/保守/廃棄等） | 構成要因 | 現状コスト比率 | 主なコストドライバー |
|------------------------------------|---------|-------------|------------------|

## 削減施策（VE的視点：機能あたりコストの改善）
| 施策 | 対象機能・要因 | 想定削減効果 | 実現難易度 | 影響範囲（品質・納期等） |
|------|--------------|------------|----------|----------------------|

## 推奨アクション
- [優先的に着手すべき施策]
```

## 品質基準
- コスト削減施策は、品質・性能・納期への影響とセットで示す
- 数値根拠（前提条件）を明示し、「感覚値」を結論として出さない
- 実現難易度が高い施策は、その理由も添える
- 設計段階のコスト低減（原価企画）と、取得後の運用・保守まで含めた総コスト評価（LCC）を混同しない。目的に応じて使い分ける

## フレームワーク参照
- 原価企画（ターゲットコスティング）: トヨタ自動車発祥とされる原価管理手法。目標原価を先に設定し、設計・開発段階でそこに近づける考え方。VE（Value Engineering）と併用されることが多い
- VE（Value Engineering）: SAVE Internationalの Value Methodology Standard に基づく、機能分析を軸にコストと価値の関係を整理する手法
- LCC（ライフサイクルコスティング）: IEC 60300-3-3（Dependability management – Application guide – Life cycle costing）に、取得から廃棄までの総コストを評価する一般的な手順が示されている
