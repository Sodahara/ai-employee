# 経営診断的レビュー（中小企業診断士視点でのフィードバック）

小田原慎輔さんの営業・クライアント企業（既存クライアント／商談中の企業）との打ち合わせにおいて、技術PM視点に加えて「経営課題を見抜く視点」を資料・コメントに反映するためのスキル。
中小企業診断士の試験知識そのものではなく、実務で使えるフレームワークのみを厳選した knowledge/management-diagnostics-frameworks.md を土台にする。

## このスキルが発動する条件
- 「診断士視点」「経営アドバイス」「経営課題」「資料レビューして」「的確なコメントが欲しい」「お客様企業を分析して」「打ち合わせ資料に図を入れて」「商談前にフィードバックして」

## 前提
- 対象は主に二種類
  1. **提案資料・打ち合わせ資料のレビュー**（小田原さん自身が作成した資料に、経営診断的な図・観点を追加する）
  2. **打ち合わせでの的確なコメント・質問の準備**（相手企業＝既存クライアントまたは商談中の企業の経営課題を仮説立てし、鋭い切り込みを用意する）
- 小田原さんの強みは技術PM・設計プロセス（knowledge/company.md参照）。このスキルは技術的な正しさに加えて「事業として成立するか」の視点を補うためのものであり、技術PM視点を置き換えるものではない

## 手順

### A. 資料レビュー（提案書・打ち合わせ資料に図やコメントを反映する場合）
1. 資料の対象企業・打ち合わせの目的（新規提案／進行中案件のレビュー／クロージング等）を確認する
2. knowledge/management-diagnostics-frameworks.mdから、資料の論点に合うフレームワークを1〜2個選ぶ（全部当てはめない）。財務情報が薄い資料を手早く網羅的にスクリーニングしたい場合は「7. 中小企業診断の実務ツール」のロカベン（財務6指標＋非財務4視点）をチェックリストとして使う。複数組織が絡むコンソーシアム型の案件（九大OIP等）では「8. 業界連携・コンソーシアム運営の視点」も確認する
3. 資料を通読し、So What?／Why So?が成立しているか（結論と根拠が繋がっているか）を1スライド単位で確認する
4. 選んだフレームワークの象限・要素のうち、資料に**抜けている視点**を具体的に指摘する（例：「強み・機会は書かれているが弱み・脅威の記載がない」）
5. 抜けている視点について、追加すべき図表（マトリクス・グラフ・表）を具体的に提案する。図の種類・軸・入れる場所（スライドNo.）まで示す
6. 数字（市場規模・財務指標）が出てくる場合は、前提条件・根拠が明記されているか確認し、不足していれば指摘する

### B. 打ち合わせ前の的確なコメント・質問準備
1. 相手企業の業種・規模・現在の経営課題（既知の情報）を確認する。不明点はNotionの議事録DB・過去のやり取りを確認する
2. knowledge/management-diagnostics-frameworks.mdの「6. 中小企業特有の論点」も必ず確認し、資金・人材・事業承継等の制約を見落とさない
3. フレームワークを使って、相手企業が「言っていること」と「言っていないこと（抜けている視点）」を整理する
4. 抜けている視点から、鋭い質問を3〜5個作る（批判的な指摘ではなく、相手が答えに詰まる／本質を突く問いにする）
5. 以下のフォーマットで報告する

## 出力フォーマット（打ち合わせ準備用）
```
# [相手企業名] 打ち合わせ準備（経営診断的視点）／YYYY-MM-DD

## 現状の理解（ファクト）
- [相手企業が既に言っている/資料にある事実]

## 使ったフレームワーク
- [選んだフレームワーク名とその理由]

## 抜けている視点・論点
- [フレームワークの象限・要素で、資料/発言に欠けているもの]

## 的確な質問・コメント案
1. [質問] — [意図：何を見抜くための質問か]
2. ...

## 資料に追加すべき図表（資料レビューの場合）
- [スライドNo.]：[追加する図の種類（例：SWOTマトリクス）]／[軸・内容]
```

## 品質基準
- フレームワークを並べるだけで終わらせない。必ず「次に聞くべき質問」または「資料に追加すべき図」まで落とし込む
- ファクトと推測（仮説）を明確に分ける。相手企業について断定しすぎない
- 技術PM視点（knowledge/company.mdの提供価値）と矛盾・重複しないか確認する。技術的な実現可能性の議論と、事業として成立するかの議論は別の軸として両方残す
- 中小企業・ハードテック企業特有の制約（資金・人材・規制・事業承継）を一般論のフレームワークだけで終わらせず必ず加味する

- 日本語の資料・コメント文の推敲 → japanese-writing-technique スキル
- 議事録からの経営課題抽出 → skills/meeting-notes/SKILL.md
