# 提案書・資料作成

## このスキルが発動する条件
- 「提案書」「資料作成」「スライド」「ドキュメント」「企画書」

## 手順
1. 目的・対象読者・ゴールを確認する
2. 構成案をまず出して、小田原慎輔に確認
3. 承認後、本文を作成
4. 見た目を整えて完了

## 品質基準
- 結論ファースト。最初に要点が伝わる構成にする
- 見た目の丁寧さを重視（余白・見出し・箇条書きのバランス）
- 1スライド1メッセージ。詰め込みすぎない
- 冗長な文章は箇条書きに変換する

## NGパターン
- ダラダラ長い文章の資料
- 見出しなしのベタ打ちテキスト
- 情報の整理がされていない資料
