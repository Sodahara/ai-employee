# ハードテックベンチャー・防衛重工向けマーケティング＆営業

想定顧客（重工業・防衛・再生可能エネルギー領域のハードテック企業で、技術PM不在／設計プロセスが属人化している中堅・ベンチャー）に対する
「認知されて指名される」ためのマーケティングと、「案件を具体的に獲得する」ための営業を一体で取りまとめる統合スキル。

- 案件ごとの進捗管理・案件トラッカー運用は skills/sales-pipeline/SKILL.md に委譲する（このスキルでは重複させない）
- ターゲット顧客・チャネルの詳細定義は Notion「営業戦略の具体化（2026-10）」「ビジネスモデルの具体化（2026-10）」を正とする

## このスキルが発動する条件
以下のような言い回しで発動する（完全一致でなくてよい）：
- 「発信ネタ考えて」「LinkedInに書く内容考えて」「業界内での知名度を上げたい」
- 「ハードテック向けの営業戦略」「防衛重工の案件を取りたい」「指名される状態を作りたい」
- 「マーケティングと営業をまとめて」「ブランディングどうすればいい」

## 共通コンテキスト（毎回参照する前提情報）
他のスキルと二重に質問しないよう、作業前に必ず以下を参照する：
- 想定顧客・強み・提供価値：knowledge/company.md、Notion「営業戦略の具体化（2026-10）」のターゲット顧客候補表
- 事業環境・ポジショニング：Notion「ビジネスモデルの具体化（2026-10）」（PEST・3C・4P・SWOT）
- 案件の進捗・チャネル実績：skills/sales-pipeline/SKILL.md が扱うNotion案件トラッカー

### 想定顧客（再掲）
- 重工業・防衛・再生可能エネルギー領域の中堅・ベンチャー企業で、技術PM不在／設計プロセス属人化の課題を持つところ
- 大学発シーズの事業化支援先（九大OIP経由のネットワーク）
- 詳細はNotion「営業戦略の具体化」ページのターゲット顧客候補表を参照

## マーケティング（信頼構築のための発信）

ハードテック・防衛領域は機密性が高く、広告的な集客よりも「業界内で名前が知られている状態」を作ることが有効。

### 手順（依頼を受けたら、まず以下を順に確認する）
1. 発信の目的を確認する（新規接点作り／既存人脈への再浮上／特定企業へのアプローチ布石　等）
2. 発信テーマを選ぶ（本人の実務知見に根ざしたものを優先）
   - 技術PMの型（WBS・開発Gate・クリティカルパス運用）
   - 認証・安全対応（船級協会対応等）の勘所
   - 原価企画・LCC分析の考え方
   - 設計ノウハウ・暗黙知の言語化手法
   - 生成AI・LLMを活用した設計プロセス効率化（本人の強み・志向と直結）
3. 発信チャネルを選ぶ：LinkedIn（業界関係者とのつながりが多い）を主軸とし、業界内の勉強会・カンファレンス登壇機会があれば優先的に提案する
4. 実績の見せ方を設計する：守秘義務・NDAに抵触しない範囲で、案件を匿名化・抽象化して「どんな課題をどう解決したか」を語る（企業名・機密技術情報は出さない）
5. 発信内容のドラフトを以下のフォーマットで作成する（文体の整形は skills/content-creation/SKILL.md に委譲）

```
# 発信ドラフト（[テーマ]）

## 投稿文（LinkedIn想定）
[本文]

## 想定読者・狙い
- [誰に向けて、何を感じてほしいか]

## 確認事項
- [匿名化・NDA面で問題ないか、本人確認が必要な箇所]
```

### 品質基準
- 防衛関連案件の内容は特に機密保持契約・情報管理規程に抵触しないか、発信前に必ず本人に確認を取る
- 「すごさ」のアピールより「何に困っている企業の助けになるか」を軸にする
- 発信頻度より質を優先し、専門性の一貫性を保つ

## 営業（案件開拓・クロージング）

### 手順（依頼を受けたら、まず以下を順に確認する）
1. アプローチ対象を確認する（新規発掘／既存人脈の掘り起こし／マーケティング経由の反応への返信、のどれか）
2. マーケティングで反応があった相手（問い合わせ・紹介・LinkedIn経由の接触等）を、skills/sales-pipeline/SKILL.mdの案件トラッカーに新規登録する
3. 既存人脈（西日本スターワークス・中部電力・住友重機械マリンエンジニアリング等）への能動アプローチは、「稼働余力があること」を端的に伝える一言連絡から始める（売り込み色を出しすぎない）。ドラフトは以下のフォーマットで作成する

```
# 営業アプローチ・ドラフト（[相手・会社名]）

## 連絡文面
[本文]

## 狙い・背景
- [なぜ今このタイミングで送るか]

## 次のアクション
- [返信が来たら／来なかったら、それぞれどうするか]
```

4. 商談時は、相手の課題（技術PM不在・設計プロセスの属人化等）をヒアリングし、knowledge/company.mdの提供価値と結びつけて提案する
5. 正社員前提・強みに合致しない求人には応募しない（skills/sales-pipeline/SKILL.mdの品質基準と同じ）

### マーケティングと営業の接続
- マーケティング発信で接点ができた相手は、即座の営業ではなく、まず関係構築（情報交換・壁打ち相手になる）を経てから案件化を狙う
- 案件トラッカーの「チャネル」列に「発信経由」等を追記できるようにし、どの発信がどの案件に繋がったかを追跡する

## 品質基準（全体）
- 広く浅く「できること」を並べるのではなく、ターゲット顧客の具体的な課題に刺さる内容に絞る
- 機密性の高い領域（防衛）を扱うため、公開情報と非公開情報の線引きを常に意識する
- 一度の発信・一度の営業アプローチで完結させようとせず、継続的な関係構築として捉える
